| 文件/类别 | 处理方式 |
|---|---|
| R/tables/by_sample/ERR*/... | 分样本归档表；若已使用对应合并表，不再追加一次 |

| kraken.output | 每条read的分类明细；不是终表。kraken.report则要保留，因为包含科/属/门汇总 |
| clean.fastq.gz、host_removed.fastq.gz | 分析中间输入，复跑/抽样时有用，不直接上传作图 |
| multiqc_report_data/*plot*.txt、multiqc_data.json | 报告缓存/辅助展示；尤其Family Top-N小表不是完整九样本科级矩阵 |
| status、validation、日志、校验与参数JSON | 运行审计和排错材料，不是生物学丰度结果 |
| deliverables/*.tar.gz | 交付包，内部同时包含终表和报告材料 |

以ERR3450203抽查的物种表和通路表为例，报告副本与节点表在统一换行后全文一致；包装程序会重新写入文本并脱敏路径，文件字节哈希可能因换行等格式变化不同。不能只按同名或只按字节哈希决定合并；以样本、特征与数值内容核对，勿重复计数。
