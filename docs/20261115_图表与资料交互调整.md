# 2026-11-15 图表与资料交互调整

## 绘图数据和参数

所有图型的数据矩阵、分组信息均使用完整文件滚动视图，移除行数提示和翻页按钮。接口一次返回受支持的完整绘图输入，页面按滚动位置渲染可见行，支持编辑末尾行；绘图输入仍限10 MB、50000行，超限明确提示先筛选。

宽表模式隐藏长表的特征列、数值列、保留特征数，这三项不参与宽表绘图。CLR和数值转换仍按用户设置执行。对数转换名称统一为ln(x+1)（自然对数）、log₂(x+1)（以2为底）；代码中的log1p对应ln(x+1)。PCA另提供CLR（中心化对数比）。

组成图的“柱子表示”改为“展示层级”，选项为“按样本展示”“分组汇总（样本等权均值）”。配色仅在绘图参数中保留有效入口，分类色系、热图色系和富集色条均展示色条。

标题行提供“显示标题、显示x轴标题、显示y轴标题”三个独立开关，右侧为操作说明。轴标题开关实际作用于渲染和PNG/SVG/PDF导出。移除数据页操作长句和帮助中的九样本复现限制段落。

## 图例列表

图例改为拖拽手柄、颜色方块、名称输入框、显隐加减按钮的紧凑列表。拖拽只调整图例顺序；隐藏图例保留对应的数据系列。颜色和名称修改会重绘并同步导出。添加的自定义图例属于显示注释，不会生成新的数据类别。

下方支持添加图例、按每行一个名称批量编辑、重置。重置恢复原数据图例名称、顺序、显隐与默认色，移除自定义注释。参数存入独立图表版本，后续再次编辑可恢复。当前HTTP入口使用兼容的随机标识生成方法。

## 资料选择和编辑

文件夹与文件一样可以勾选；勾选后上方统一显示“移动、重命名、删除”，重命名每次限一项。文件夹行移除操作按钮，文件行保留“来源、编辑、下载”，点击文件名仍可预览。

文本表格编辑限2 MB，保存为新版本，保留原文件和来源关系。图表的编辑进入SVG参数编辑器；不支持文本编辑的格式会提示。文件重命名采用资料显示名称，不改动分析计算路径；删除文件从当前任务资料列表移除，保留原始文件。删除文件夹沿用文件保留到上级的行为。

“生成元数据”接受文件和文件夹选择。文件夹递归包含子目录中的测序样本，R1/R2及重复选择按sample_id去重；目录内非测序文件不参与。CSV仍为sample、group、batch，后两列留空，归档到元数据目录。

底部左侧为生成元数据，中间分页，右侧为已登记、刷新目录、显示全部记录/隐藏已知异常文件。
