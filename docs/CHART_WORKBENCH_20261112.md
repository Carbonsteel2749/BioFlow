# 图表工作台与任务结果目录更新（2026-11-12）

## 已实施的界面

- 总系统的原“模型与能力”入口改为 Skill 库；原技能入口改为算法库。两者直接复用现有原生模块的内容、功能和排版；未修改技能模块内部侧栏和构建资源。
- 12 类绘图卡片：透明背景真实模拟绘图、图名与分类标签、生信用途、输入格式、使用模板、对应 Skill、示例下载。
- 使用模板进入完整页面，左图右参数。右侧为数据文件、基本参数、绘图参数三个标签页。
- 矩阵与分组分别上传（CSV/TSV/制表符 TXT），按样本编号匹配；表格分页预览，页面不加载整份大结果。
- 样本矩阵支持两种方向；PCA/热图支持长丰度表按样本与特征透视，并显式选择保留的最高丰度特征数。非样本型图使用结果表自己的类别列，关闭不适用的分组上传控件。
- 参数影响真实转换/绘图。PCA 支持 CLR/log1p/标准化/标签；热图支持标准化、对数、聚类开关、距离、连接和色系；其他图按图型提供丰度聚合、区间、阈值、线宽、网络、透明度等参数。
- 通用标题、坐标轴、刻度、图例、标注字号分别设置；支持显示开关、色系、逐系列颜色、精确位置。
- SVG 双击修改标题/轴标题/图例文字，拖动标题/图例。新参数重新进入同一绘图程序；保存含修改的独立版本，PNG/SVG/PDF 同步。修改后旧下载链接停用，避免下载旧文件。
- 报错直接显示在图片位置；当前任务来源同时由界面和后台检查。
