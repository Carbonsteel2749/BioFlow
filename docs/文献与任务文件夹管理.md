# 文献保存与任务文件夹管理

更新：2026-11-15。使用入口：http://219.224.3.96:8804/ ，按 Ctrl+F5 刷新。

## 个人文献库

“添加文献”位于搜索行右侧。可填写文献URL，或上传PDF、Markdown、DOCX、TXT、BibTeX、RIS、ENW；点击确认才保存，单文件上限50 MB。

URL保存为链接条目，本地文件保存原件。两种方式均不自动建立向量索引，不调用嵌入模型，不自动加入公共库。用户之后可以关联项目，沿用项目知识库索引流程；提交公共库仍走管理员审核。

个人文件保存在 `runtime/personal-library/<用户ID>/`，数据库记录用户范围内的相对路径、校验值和条目信息。列表只读小型元数据。同一账户重复添加相同内容会复用条目，账户之间互相隔离。

## 数据与运行结果库

布局顺序：分类索引 → 已登记/刷新/显示全部/搜索/上传 → 文件夹路径及管理 → 文件夹列表 → 文件列表 → 选中文件预览。分页在内容底部。

上传时先选择分类，在该分类点击上传，再选目标文件夹或新建文件夹。可选择普通文件，也可上传整个文件夹并保留目录结构，使用原有可续传队列。文件分类由当前页确定；FASTQ只能归入测序数据。任务、分类、文件夹均在确认时固定保存。

用户可以新建子文件夹，移动所选文件，并通过文件夹行右侧的重命名、移动、删除操作管理文件夹。删除目录及子目录时，文件保留在上级目录，原始文件不删除。搜索查找当前任务、当前分类内的文件，包括其他文件夹，并标注归属。

## 统一自动归档规则

系统文件以“项目空间＋任务＋分类＋分析节点标识”为文件夹身份。节点产生的同类文件归入同一个文件夹；刷新时补齐新文件和历史文件，文件名相同不作为合并依据。自动文件夹名称来自分析步骤，如质量检查、质量过滤、物种分类、功能注释、汇总报告。未产生可展示文件的步骤不建立空壳目录。

绘图输入整理作为“作图输入”进程保存；已保存的独立图表版本按绘图模板进程归档，例如“绘图 · PCA”“绘图 · 堆叠柱状图”。上传文件使用用户选择的目录，不因扩展名而被挪到其他分类。手动移动的归属优先于自动规则，刷新不会改回。

文件夹是目录索引：不搬动原始计算文件、不改写源数据、不改变已有文件的相对路径、标识或图表来源关系。系统文件夹初始名称来自分析进程；用户重命名或移动后会保留自己的设置。

## 按需预览

- CSV/TSV：不超过5 MB，显示前100行、50列。
- TXT/Markdown/JSON/日志/Kraken报告：不超过1 MB，最多显示50000字符。
- PNG/JPEG/WebP/SVG：不超过10 MB。
- PDF：不超过20 MB。
- 其他格式、未挂载文件、超过上限的文件：直接说明无法预览原因，可使用下载入口。HTML报告目前通过下载或原报告入口查看。

目录列表不会读取文件正文；只有点击预览时才读取对应文件。原有“来源”入口继续展示分析过程和数据关系。
