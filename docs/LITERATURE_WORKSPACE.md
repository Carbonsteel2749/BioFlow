# 文献库与检索问答

## 页面与入口

- 顶部固定栏统一显示“个人文献库”或“知识库与问答”，正文通过同一组页签切换。
- 个人文献按行展示标题、作者、年份和文件状态；支持上传、筛选、编辑题录、关联/解除关联项目。
- 检索页可切换“文献检索 / 大模型问答”，来源可选系统知识库、联网或两者。
- 系统检索只读取当前账户可访问项目的文献目录；存在已索引文献时调用对应知识库的全文检索接口，并按文献合并命中的片段。
- 联网检索使用 Crossref REST API 的公开题录。每行右侧 ＋ 将文献保存为 RIS 条目，按 DOI 或标题检查重复。
- 收藏题录不代表取得 PDF。页面分别标注 PDF 已保存或条目已保存、暂无 PDF。PDF 可通过上传入口保存。

Crossref API 文档：https://www.crossref.org/documentation/retrieve-metadata/rest-api/

## 问答与模型连接

- 问答携带唯一会话标识，限定当前项目知识库，并将检索条目作为依据提交；没有依据时要求模型明确说明。
- 项目未关联知识库时，首次问答会创建并关联项目自己的知识库，避免默认检索其他项目。
- 已恢复文献容器原先缺失的模型桥接：Docker 私有接口 `172.17.0.1:11435` 转发到本机 `127.0.0.1:11434`。
- 桥接只允许模型查询、向量和生成端点，限制请求大小；Qwen3-14B 关闭长推理，限制512输出 token、8 CPU线程。
- 文献聊天模型与平台一致，使用 `qwen3:14b`；保留原 `paraphrase-multilingual` 向量模型，未重建或替换向量库。
- `deploy/server96.py` 下次启动会检查并恢复缺失的桥接进程。
