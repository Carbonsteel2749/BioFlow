# 研究首页、数据工作台与结果报告

本次按用户的六项界面调整实现，继续在 feature/unified-research-entry 分支和 8807 独立预览环境开发。

## 页面分工

首页是研究 Agent 入口，左侧首个图标进入首页。研究目标、输入选择、AI/手动方案、确认执行和运行记录放在首页。尚未建立项目时也能填写目标，添加数据时建立项目并保留草稿。

数据分析页改为数据工作台：左侧上传及数据版本，右侧识别结果、样本匹配信息、可编辑表格及 AI 修正。上传使用真实 XHR 进度；字节传输完成后显示识别阶段，完成登记后再提示成功。

## 数据识别与版本

MetaPhlAn、HUMAnN 和有明确编号字段的元数据自动识别；无法确认含义的表格保留为普通表。Excel 优先选择实际编号列（例如 F号），结合已登记样本核对匹配。HUMAnN _combined 后缀只在去除后与已登记编号完全一一匹配时自动处理，保存显式映射。

用户可以直接修改单元格，也可以用自然语言提出读取设置或明确单元格新值。AI 返回建议，展示旧值和新值，确认后才保存。禁止凭空填补数值、推测分组。所有修改另建数据版本，已有方案和结果保留原输入。一次同时改变读取方式与单元格时要求分两次处理，避免错用行列位置。

## 资料与任务

资料库默认展示整个项目，不要求先建分析任务。上传、文件夹、预览、编辑和元数据生成支持项目范围；原任务归属继续记录，不删除历史关联。数据工作台和资料库复用同一原文件登记。

AI 规划生成短标题，完整研究目标保留在方案中。旧任务用工具概括作为兼容标题。首页轮询同步运行卡片与左侧任务状态。

## 结果报告

任务完成时生成结构化真实结果汇总；首次打开报告时根据已记录证据生成并缓存 AI 解读。报告展示摘要、方法、指标、图片、文件下载和输入版本，运行事件放入次要折叠区。解读必须引用已有步骤，禁止新增未记录数值；模型不可用时仍可查看真实结果。

Alpha 多样性公式使用 MathML。补齐 Noto Sans SC 中文字体及 OFL 授权，避免新生成图中文字缺失。报告可下载为 HTML；图片和产物链接仍遵循项目权限。

所有普通弹窗限制在视口内，长内容在弹窗内部滚动。

## 验证

- 39 项相关集成与回归测试通过，覆盖识别、匹配、版本、项目级资料库、队列及历史接口。
- Edge 完整验证：首页、上传进度、自动识别、单元格修改、新版本、无需任务入库、方案执行、报告图片及内部滚动；未出现页面脚本错误。
- 独立浏览器验证：无分析任务时在资料库创建文件夹并直接上传成功。
- 实际 191 样本输入验证：AI 短标题、后台分析及证据报告；元数据识别 F号；功能表识别物种分层。
- 使用实际模型验证读取设置修正及明确单元格修改；原版本保持不变。
