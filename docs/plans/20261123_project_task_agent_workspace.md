# 项目、任务与 Agent 工作区

## 关系与入口

Agent、能力、算法、知识库是全局模块。项目拥有任务；任务持久保存对话、输入版本、方案版本和运行引用。Agent 入口开始新任务草稿，选择项目后第一次发送或上传时建立任务；未选项目时自动建立项目。项目树支持展开、创建任务、改名、归档和删除。

已有统一分析运行和旧流程任务按稳定 ID 迁移为任务引用，保留原始运行、文件、计划及历史，不复制执行。已归档任务可通过树接口 include_archived 查询，删除仅隐藏任务引用。

## 数据与方案

任务默认无输入。上传或明确选择项目文件后，建立 task_id 与资产、不可变数据版本的关联。同项目复用文件；跨项目验证所有权及哈希后建立副本。原项目资产仍保留。任务内文件管理沿用目录、编辑和下载；上传进入数据识别与编辑工作台。

Agent 对话、可视化流程与执行使用同一份 canonical plan。修改生成新版本，确认使用 fingerprint 固定快照。运行期间流程界面显示冻结版本。用户可拖动节点、连接依赖、修改参数并保存为新版本。高级参数保留 JSON 编辑。

运行记录按消息引用显示，结束后在同一位置展示 Markdown 报告。刷新恢复当前任务，运行状态后台更新；报告来自实际结果，并调用已有结果解读接口。

## 原模块复用

能力、算法通过 skill_center_entrypoint 挂载原生 Skill Center 前端与接口。普通 app 入口不挂载该模块；部署应启用 BIOFLOW_SKILL_CENTER_ENABLED，并指定已有 BIOFLOW_SKILL_CENTER_DATABASE。预览使用独立平台数据库与原 Skill Center 库。

文献可留在个人库未分类或关联一个或多个项目；项目关联只建立原件引用，不触发向量索引。任务选择项目文献。图表工作台与写作界面保留原组件，套用任务导航，写作会话和图表引用按任务筛选。

前端按固定顺序加载图表、文件管理器、数据工作台、任务外壳，再启动登录和初始渲染，避免迟到脚本覆盖新页面。

- unified research 后端 17 项测试通过；另增跨项目输入、任务归属、文献引用及不自动索引测试通过，另增编辑输入后更新流程快照的测试，共 19 项。
- gateway、library_management、provenance、chart_workbench 26 项回归通过。
- 浏览器实测：建项目、空任务上传、识别、Agent V1/V2、手动 V3 修改样本范围、确认执行、实际样本数验证、Markdown 报告、刷新恢复、图表与写作入口、能力和算法原生页面、知识库和折叠导航。另实测个人文献关联项目、任务选文献、空任务上传界面、归档及恢复；浏览器 pageerror 为零。
