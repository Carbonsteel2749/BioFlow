## 图表

进入“图表”后按功能选择 PCA、火山图、聚类热图、富集气泡图、GSEA、ROC、PPI、韦恩图、GO 富集直方图或桑基图。每个图型有独立 Python 程序和固定输入说明，可下载示例 CSV。

选择当前项目上传的 CSV/TSV 表，或已登记的分析结果表。列名不同时，在“列名对应”中填写，例如 `pvalue=padj`。PCA 的输入行是样本，列是数值特征；默认中心化，可选特征标准化。输入预览最多支持 10 MB、50000 行，聚类与网络图另有图型规模限制。

生成首次预览后，可修改标题、坐标轴名称、图例显示名称、顺序和位置。每次更新创建新版本，复用同一数据快照；底层分组与样本标识保留。点击“保存到项目图表”后进入项目资料，支持导出 SVG、PDF、PNG。原版本继续保留。SVG 保留文字，当前通过参数编辑，不提供自由拖动排版。

“宏基因组绘图”保留原任务、标准结果表及绘图版本入口，已有成功版本提供“编辑显示参数”。较早版本缺少图例元数据时，先重绘一次可获得完整编辑信息。已有图的标题、轴名和图例修改不会重新运行测序分析。

图型与统计输入：火山图消费已有差异分析结果；富集气泡图和 GO 图消费已有富集结果；GSEA 图展示导入的运行富集分数，不推断 NES、P 值；ROC 由真实二分类标签和预测分数计算，不训练模型；PPI 展示导入的互作边表；韦恩图支持 2–3 个集合，交集数字精确，圆面积为示意；桑基图展示两层来源—去向流量。图中出现的统计输入须由对应分析产生。

## 资料与个人文献

项目资料提供“上传文献”“上传测序数据与表格”“导入分析结果”“上传图表”“上传稿件”。首页“＋”也可添加这些文件。开始传输前逐文件确认用途；PDF 报告可归入结果，Word 草稿可归入稿件。用途随分片会话持久保存，刷新或续传后保持原分类。外部结果可填写结果类型、来源软件并关联当前项目任务。

文献进入个人文献库，可编辑题名、作者、年份、DOI 和标签，再关联其他项目，无需重复上传原文。已有文件属性或 RIS/BibTeX 题录可自动读取，缺失信息留空并允许手动补全；PDF 属性读取使用环境中已有的解析工具。项目资料与个人文献库分别显示文件保存状态和各项目的索引状态。失败索引可重试；已有上游文献记录使用重索引接口，避免重复上传。解除项目关联保留个人文件。

## 模型与 Skills

“模型与能力”分别展示模型和 Skills，并按用途筛选。图表程序同时登记为可视化能力。模型可用状态来自原有服务；当前研究指令仍使用实际配置的 Qwen3-14B。开发者可管理启用状态、功能分类和用途说明。停用会拦截后续执行，已生成成果仍可查看和导出。

## 项目与图表选择卡片

项目列表中每个项目提供“编辑”和“删除”。编辑名称、简介后立即生效；删除需确认，从项目列表移除并禁止继续访问，原始文件和分析结果保留。

图型卡片只显示图名和模拟数据预览图，点击整张卡片进入绘图；输入格式、示例表及参数在绘图窗口显示。十张预览图打包在 frontend/chart-previews/，本地和服务器均直接读取静态图片，不在加载页面时运行绘图。

## 图表数据映射与通用参数

左侧画布宽高（英寸）、字号（pt）、标题和图例位置直接传给绘图程序。富集气泡图可分别选择横轴和气泡大小的数据字段（Count 或 GeneRatio），会实际改变横坐标和面积，并自动显示大小图例。颜色仍为 −log10(P)。坐标轴标题放在独立折叠项中，只改文字；留空时按实际映射自动命名。切换横轴字段时清除旧标题，避免旧名称误导。PCA、ROC、网络等图的计算坐标不提供无效的数据切换。

绘图错误显示在右侧图表预览位置，包含接口或绘图程序返回的具体原因，保留左侧输入便于修正重试。列名对应逐行显示固定程序字段，右侧填写上传表的表头；留空使用同名列，可选字段不必填写。选择来源表后可提示该表的实际列名。失败记录也可重新打开查看错误和修正对应。

## 按任务整理资料与来源追溯

资料页顶部可选择“全部任务”、具体分析任务或“未分类”，数据、结果、图表、稿件和文献分类均支持该筛选。资料卡显示关联任务；同一文件可关联多个任务，不复制原文。运行记录确认的归属保留，手动分类可调整；暂无关系的资料列入未分类。

每张卡片的“来源与关联”可查看输入资料、引用文献、由此产生或引用它的成果，并逐层点击追溯。任务提供进度入口及参数；已保存的新图表记录来源表、绘图参数、程序版本和快照校验值。同一任务的其他资料单独列出，不冒充直接来源。

已有任务成果按任务 ID 自动归类，新图表按来源表 ID 追溯。稿件使用已记录的分析任务 ID；新生成稿件保存实际引用列表，项目文献按相同 DOI 自动对应。历史稿件没有引用记录、外部导入成果没有来源记录时不猜测，可在面板中手动添加“来源于”“使用资料”“引用文献”；引用关系限稿件与文献，支持双向查看及解除手动关联。

关系是项目数据库里的元数据；原有相对路径、数据文件和成果均不搬移。列表只查询小型目录和关联记录，具体文件仍在打开时读取。
